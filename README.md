## The word

**Subscription**

The ex who treated the relationship like a streaming subscription:
auto-renewed until it quietly cancelled itself, no notice, no refund.

## How it works

`main.py` (Python 3.13, standard library only) writes the single word to
`entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`
(default `/output`). The output is byte-identical across runs.
